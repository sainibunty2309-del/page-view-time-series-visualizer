# Page View Time Series Visualizer

This project is part of the freeCodeCamp Data Analysis with Python certification.

## Project Overview

In this project, I used Python libraries such as Pandas, Matplotlib, and Seaborn to analyze and visualize time series data from the freeCodeCamp forum.

The dataset contains the number of page views recorded each day from May 2016 to December 2019.

## Features

- Import and clean the dataset using Pandas
- Create a line chart to show page views over time
- Create a bar chart to compare average monthly page views by year
- Create box plots to analyze yearly trends and monthly seasonality
- Save all generated charts as image files

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

## Files

- `time_series_visualizer.py` - Main project file
- `fcc-forum-pageviews.csv` - Dataset
- `line_plot.png` - Line chart output
- `bar_plot.png` - Bar chart output
- `box_plot.png` - Box plot output
